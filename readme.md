# Brooks's Web

**Brooks's Web** is a full-stack web application project demonstrating practical web development skills. It includes user authentication, dynamic content, and database integration, built using HTML, CSS, JavaScript, and Python.

## Features

- User registration and login system
- Dynamic pages with content stored in a database
- Contact or feedback form
- Admin panel for content management
- Responsive design for desktop and mobile
- Secure session handling and form validation

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)
- **Database:** SQLite
- **Version Control:** Git, GitHub
