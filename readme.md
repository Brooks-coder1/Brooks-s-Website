# Brooks's Web

**Brooks's Web** is a responsive full-stack website project that shows how a real website works behind the scenes. It includes user login, dynamic pages, and database storage. Built with HTML, CSS, JavaScript, and Python (Flask), it demonstrates practical web development skills in a clean and professional way.



**Used here Python as a backend language to good support and to make a strong backbone of web**

## Features

- **User Authentication:** Users can register, log in, and log out securely.
- **Dynamic Pages:** Content is loaded from the database and updates automatically.
- **Contact Form:** Users can send messages or feedback easily.
- **Admin Panel:** Manage website data and content from a simple dashboard.
- **Responsive Design:** Works smoothly on desktop, tablet, and mobile screens.
- **Secure Sessions:** Protects user data and validates forms properly.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Flask)  
- **Database:** SQLite  
- **Version Control:** Git, GitHub
